# DataExporter 模組任務清單

本模組負責格式化填寫結果，並將其導出為包含時間戳記的 JSON 檔案下載。

## 最小執行任務

- [x] **任務 1：實作時間戳記格式化方法**
  - **目標**：實作 `getFormattedTime()`，依需求輸出符合台灣本地習慣的時間格式：`YYYY/M/D 下午 H:MM:SS`（例如 `2026/5/23 下午 9:40:00`）。
  - **驗證**：傳入一個特定的 `Date` 實例，驗證輸出的字串是否嚴格符合格式。
- [x] **任務 2：構建匯出 JSON 資料結構**
  - **目標**：將時間戳記作為 `export_at`，並將傳入的 `formData` 內容拷貝至 `results` 屬性中，確保不包含額外的無用狀態。
  - **驗證**：傳入 `{ "項目A": true }`，驗證產生的物件是否包含 `export_at` 與內含正確資料的 `results`。
- [x] **任務 3：實作 Blob 封裝與瀏覽器下載觸發**
  - **目標**：將 JSON 字串轉為 UTF-8 編碼的 Blob，建立臨時 `<a>` 標籤，設定檔名為 `checklist-YYYYMMDD.json`（依據當天日期），觸發點擊後撤銷 URL 物件。
  - **驗證**：在瀏覽器上呼叫方法後，確認瀏覽器能正常彈出下載對話框，下載的檔名與內容完全符合規格。
