# 需求規格書 (Requirement Specification) - 內嵌 Markdown 離線版

## 1. 專案目標 (Project Objective)

本專案旨在開發一個**完全免網頁伺服器（Zero-Server）、免本地託管服務**的單一 HTML 確認清單播放器。系統將 Markdown（以下簡稱 MD）題目範本直接內嵌於 HTML 內部的特定的 `<script>` 標籤中。透過用戶端瀏覽器即時讀取內置的 MD 文本並進行解析，將其渲染為具備動態互動能力的表單。使用者填寫完畢後，資料可於地端結構化導出 JSON，達成**純離線、雙擊即開、零設定**之維護與發布體驗。

## 2. 系統架構與佈署模型 (Deployment Model)

### 2.1 檔案結構

本系統完全不依賴外部相依檔案或相對路徑請求，整體系統僅包含一個實體檔案：

Plaintext

```
📄 index.html  (整合主程式、解析引擎、樣式框架與 MD 題目文本之單一檔案)
```

### 2.2 運作時序 (Runtime Sequence)

1. **讀取階段**：使用者於本機雙擊開啟 `index.html`（網址列為 `file:///` 協定）。Vue 3 啟動後，直接讀取 DOM 中 DOM id 為特定的 `<script type="text/markdown">` 標籤內的 text 內容。
2. **編譯階段**：`markdown-it` 解析引擎獲取該 MD 字串，依據語法轉換為包含特定 `data-key`、`name` 的標準 HTML 表單標籤。
3. **渲染階段**：Vue 3 將轉換後的 HTML 字串透過 `v-html` 渲染至頁面指定區塊。
4. **交互階段**：使用者進行單選、複選、問答輸入，系統透過事件代理（Event Delegation）即時更新內部的 JSON 資料物件（`formData`）。

## 3. 功能需求 (Functional Requirements)

### 3.1 內嵌文本提取功能

- **DOM 文本存取**：系統在生命週期掛載（Mounted）時，必須能準確擷取指定 ID 標籤內的原始 MD 內容，且不受 HTML 轉義字元的干擾。

### 3.2 語法解析與表單生成規則 (依使用者定義確認)

系統需完整支援以下四種題型的解析與轉換，其資料收集鍵值（Key）規格如下：

- **複選題**：
  - _語法_：標準 MD 語法 `- [ ] 題目文字`
  - _鍵值 (Key) 定義_：**直接抓取題目文字**。例如選取後產生 `"伺服器規格確認": true`。
- **單選題**：
  - _語法_：自訂語法 `( ) 群組名稱：選項文字`
  - _群組與文字邏輯_：**採用冒號分組**。以冒號 `：` 前的文字作為 HTML `input[type="radio"]` 的 `name` 屬性（即群組鍵值），冒號後的文字作為該選項選中時的值（Value）。
- **單行問答**：
  - _語法_：自訂語法 `[text: 提示欄位名]`
  - _鍵值 (Key) 定義_：以 `提示欄位名` 作為 JSON 的 Key，使用者輸入的文字作為 Value。
- **多行問答**：
  - _語法_：自訂語法 `[textarea: 提示欄位名]`
  - _鍵值 (Key) 定義_：以 `提示欄位名` 作為 JSON 的 Key，使用者輸入的多行文字作為 Value。

### 3.3 資料收集與在地端匯出功能

- **動態狀態同步**：使用者變更任何表單元件時，資料必須即時寫入記憶體中的鍵值對（Key-Value Pair）。
- **一鍵下載 JSON**：提供按鈕將記憶體中的資料序列化為 JSON 字串，並透過 Blob 封裝，觸發瀏覽器下載為 `.json` 實體檔案，檔名需包含當前日期。

## 4. 介面與使用者體驗需求 (UI/UX Requirements)

- **外觀美化**：採用 Tailwind CSS 渲染，清單需具備良好的行距、字體層級（Heading）與表單控制項樣式（如 Focus 藍色外框、圓角等）。
- **離線支援**：所有的套件（Vue, markdown-it）雖然在此原型中使用 CDN 連結，但需求設計上必須保留可隨時改為本機相對路徑載入的彈性，以支援完全斷網環境。

## 5. 數據結構規格 (Data Schema)

當使用者填寫完畢並點擊匯出時，產出的 JSON 檔案結構必須嚴格符合以下定義：

JSON

```
{
  "export_at": "2026/5/23 下午 9:40:00",
  "results": {
    "項目 A 複選確認": true,
    "項目 B 複選確認": false,
    "佈署類型": "全新安裝 (Clean Install)",
    "驗收負責人": "黃oo",
    "備註與異常說明": "本地測試完全正常。"
  }
}
```
